# 今天喝哪家？ Drink Shop Draw

一款協助解決「今天要喝哪家飲料」選擇困難的網頁工具。

使用者可以管理候選店家並進行隨機抽選，也能查詢常見連鎖飲料品牌的品項、價格與資料來源，從選店到看菜單都能在同一個頁面完成。

## 線上體驗

https://dawn-hsu.github.io/drink-shop-draw/

## 主要功能

- 隨機抽選飲料店
- 自訂新增或移除候選店家
- 選擇哪些店家參與抽籤
- 支援重新抽選與確認結果
- 從抽選結果直接查看該品牌菜單
- 整理 20 家常見連鎖飲料品牌
- 支援搜尋品牌與飲品
- 顯示飲品分類、品項與參考價格
- 提供資料確認日期與來源連結
- 支援桌機與手機版面

## 使用方式

1. 在「抽店家」頁面管理候選店家。
2. 選擇至少兩家店參與抽籤。
3. 點擊「開始抽店家」產生結果。
4. 可選擇再抽一次、確認店家或查看該品牌菜單。
5. 在「品牌菜單」頁面搜尋品牌或飲品。

## 菜單資料說明

菜單品項與價格依公開資料整理，並於頁面標示最後確認日期及相關來源。實際品項與售價可能因地區、門市、特殊店型或期間活動而不同，請以品牌官方及現場公告為準。
